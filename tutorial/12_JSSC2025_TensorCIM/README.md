# TensorCIM 多芯粒数字 CIM 张量处理器零基础精讲 · IEEE JSSC 2025

> TensorCIM: Digital Computing-in-Memory Tensor Processor With Multichip-Module-Based
> Architecture for Beyond-NN Acceleration（IEEE JSSC, vol.60, no.2, 2025 · 清华+港科大）

## 打开方式

**用浏览器直接打开 `index.html` 即可**（无需服务器）。内嵌 3 个交互 Canvas 仿真、
3 个 MP4 演示视频、9 张教学 SVG 图、3 张数据图及论文原图。

## 目录结构

```
12_JSSC2025_TensorCIM/
├── index.html          ← 教学主文件（单文件）
├── assets/
│   ├── style.css / app.js
│   ├── diagrams/       ← 9 张教学 SVG（Beyond-NN/MCM/REGM/EOCI/ILA/架构/结果）
│   ├── charts/         ← 3 张数据图（能效/技术分解/利用率）
│   ├── videos/         ← 3 个 MP4（REGM/EOCI/ILA）
│   ├── figs/           ← 论文原图（© IEEE 2024，教学引用）
│   └── 原文论文.pdf
└── _src/               ← 源分片与构建脚本（python build.py 重新构建）
```
