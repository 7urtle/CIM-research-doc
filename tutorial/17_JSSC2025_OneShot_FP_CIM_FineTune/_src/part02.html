2.2 引擎架构（论文 Fig.3）

引擎由四大模块组成：

模块职责
ManAU（尾数对齐单元，0.018 mm²）核心级输入-权重协同对齐：直接用权重最大指数对齐输入尾数（免 XE_max 选择）
CIM Core（0.084 mm²）INT 尾数计算：输入驱动 + InADD（128 输入加法树，Σxi 共享）+ 16 列子阵列（16-kb 权重）+ ParMS + ACC-ASU
ITFU（INT→FP 单元，0.003 mm²）16 位整数结果 → UBF16 格式
ODFC（片上微调核心，0.037 mm²）在线权重更新（训练）

2.3 multiply-less 的计算分解

引擎支持 FP 与 INT 两种模式（都只需 1 周期）。FP 模式下：ManAU 对齐 → CIM core 尾数计算 → ITFU 转回 FP。核心运算沿袭第 13 篇的 multiply-less 分解（L1 距离）：

Σ|xi−wi| = Σxi + Σwi − 2·Σmin(xi,wi)

  • Σxi：InADD（128 输入 8 位加法树），结果在整个 CIM core 共享（摊薄成本）；
  • Σwi：部署前预计算存 WSUM；
  • 2Σmin：ParMS + ACC-ASU 实时完成（最轻的运算）。
💡 设计与第 13 篇的关系

第 13 篇（multiply-less INT CIM）用位串行动态比较器；本篇把它推到 BF16 浮点：尾数变成 8 位 → 用位并行的定制 ParMS（静态、进位前瞻）→ 1 周期完成。同时新增协同对齐（指数部分）和 ODFC（训练部分）——是前作的完整升级。
