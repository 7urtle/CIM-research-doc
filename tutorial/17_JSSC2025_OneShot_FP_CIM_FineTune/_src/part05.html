§5创新②：输入-权重协同对齐与 UBF16 格式

📐 本节目标

理解：① 离线权重无损钳位为什么能“无损”；② 用权重最大指数对齐输入怎么免掉 XE_max 选择；③ UBF16 怎么简化 INT→FP 归一化。

5.1 离线权重无损钳位（论文 Fig.8）

multiply-less NN 里权重范围 > 输入范围（Fig.8a）。因为运算是最小选择，结果可以提前判定：

  • 输入经 ReLU → 非负，钳到 [0, Xmax]（Xmax 由训练集得到的经验值）；
  • 权重 < 0：输入非负 → 最小值必是权重 → 无需计算 → 权重直接钳到 0，作为偏置合并（无损）；
  • 权重 > Xmax：所有输入 ≤ Xmax → 最小值必是 Xmax → 权重钳到 Xmax（无损）；
  • 注意：实际推理时输入最大值 Xinfmax 随样本变化，但 95% 的 Xinfmax < Xmax → 精度几乎不受影响；
  • 钳位还提高权重稀疏度 → 省能耗。

5.2 离线权重预对齐（论文 Fig.9）

钳位后权重分布与输入对齐 [0,Xmax] → 可以直接用权重对齐输入：

  1. 每个 CIM core 选权重最大指数 WE_max 并预存；
  2. 权重尾数按 WE_max 预对齐后存入 CIM core；
  3. 在线：ManAU 直接用 WE_max 对齐输入尾数 → 消除步骤①（XE_max 选择）；
  4. 边界情况：输入指数 > WE_max → 最小值必是权重 → ManAU 直接置输入尾数为 8′11111111。

5.3 UBF16：免符号位的 BF16（论文 Fig.11）

传统 BF16 归一化 16 位整数：尾数 MSB 是隐藏位（必须为 1）→ 要搜 16 位找最高位 1 再移位。本论文观察到：钳位后 X、W 都非负 → CIM 输出也非负 → 提出 UBF16（无符号 BF16）：

  • 最高位表示尾数 MSB（不是符号位）；
  • 尾数 MSB 可以是 0 → 搜索范围从 16 缩到 8 位；
  • 高 8 位找不到 1 → 低 8 位直接存作尾数（MSB 放 UBF16 最高位）；
  • 与 BF16 混算：UBF16 最高位直接拼 Mantissa⟨6:0⟩ 成 8 位尾数 → 正常 FP 运算（开销极小）。

💡 本节小结

① 最小选择语义允许离线无损钳位（负权重→0、超上限→Xmax）→ 权重与输入同分布；② 权重静态 → WE_max 离线预存 → 输入直接对齐（免 127 个比较器）；③ UBF16 免符号位 → 归一化 16→8 位。合计面积 −33.8%、能耗 −38.2%。
