§4创新②：预计算（Precalculation）L1 计算方案——把减法+绝对值换成“最小选择”

📐 本节目标

理解：① 朴素 L1 硬件为什么不够好；② 数学恒等式 |x−w| = x + w − 2·min(x,w) 怎么把硬件从“减法+绝对值”变成“比较+选择”；③ 权重截断怎么白捡 86× 位级稀疏度。

4.1 朴素 L1 计算的硬件问题

论文 Fig.6(a) 展示了传统 L1 距离计算方案：每个元素对要做减法（两个多位加法器）→ 取绝对值（多路选择）→ 再累加。虽然比点积便宜，但：

  • 多位加法器面积依然大——面积效率还是受限于数字逻辑；
  • 绝对值运算在累加之前必须完成 → 无法按位串行流水 → 很难利用位分布稀疏性（挑战三无解）。

4.2 核心恒等式：|x−w| = x + w − 2·min(x,w)

对任意两个数 x 和 w，都有：

|x − w| = max(x,w) − min(x,w) = (x + w) − 2·min(x,w)

把它代入 L1 距离并对 i 求和：

Σ|xi − wi| = Σxi + Σwi − 2·Σmin(xi, wi)

现在看三项各自的硬件成本：

项含义硬件处理方式
Σwi（WSUM）所有权重之和权重是静态的 → 模型编译期预计算好，存进 SRAM 的额外列（每列仅 15 个额外单元）→ 实时成本为零
Σxi所有激活之和由 ActACCU（激活累加器）逐位累加，结果广播共享给全部 16 个阵列 → 摊薄成本
2·Σmin(xi, wi)最小值和 ×2实时只需比较器选最小值 + 累加器（MinSEL + MinACCU）→ 最便宜的运算

对比传统方案：减法 + 绝对值 + 累加 → 新方案只剩比较（min）+ 累加，绝对值和减法全部消失。论文报告：面积缩减 1.5×。这就是“预计算”的名字由来——把能提前算的都提前算掉（Σw），实时路径只剩最轻的运算。

💡 直觉：把“贵的运算”变成“便宜的运算+提前做”

减法器贵（多位加法）而且破坏位串行；min 选择便宜（比较器）而且天然按位比较。预计算的精髓是：能离线算的绝不实时算（Σw），能共享的绝不重复算（Σx 广播），实时只保留最便宜的（Σmin）。这就是“架构级近似”：不改算法语义，只改运算分解。

4.3 权重截断：把负权重归零并并入 WSUM

既然 ReLU 激活非负（xi ≥ 0），论文进一步做了一步数学变形（论文式 2）：

Σ|xi − wi| = Σ|xi − clamp(wi, 0, wmax)| + Σ|wi|

直观理解：x ≥ 0 时，min(x, w) 与 w 的负值无关（负数不可能被选中），所以可以把负权重截断到 0（clamp 到 [0, wmax]），截掉的部分（Σ|wi| 中负权重对应的项）作为常数并入 WSUM——计算结果完全不变（等效计算）。这一步带来两个巨大的硬件红利：

  • 权重稀疏度暴增：截断后大量权重变成 0。论文 Fig.7 的数据：ResNet-20（CIFAR-10）模型，预计算后权重稀疏度提升 86×！→ L1 计算单元的活动因子（activity factor）大幅下降 → 比较运算功耗降低；
  • 全部非负：权重和激活都是非负数 → 不需要符号位、不需要补码 → 位宽减小、电路简化。
⚠️ 注意：稀疏度提升 ≠ 结构性稀疏

这里的稀疏是位级、非结构化的（每个比特的 0/1 分布）。它不需要稀疏训练，也不需要稀疏索引/跳零逻辑，而是通过电路行为（预充保持 + 提前停止，§6）自动省电。这正是挑战三的解法：用电路设计去“白捡”天然稀疏。

4.4 小结与硬件收益汇总

  • 预计算分解：减法/绝对值 → 最小选择 → 面积 −1.5×；
  • WSUM 预存：每列仅 15 个额外 SRAM 单元；Σx 广播共享；
  • 权重截断：权重稀疏度 +86×、无符号位 → 位宽减、电路简；
  • 为 §6 的位串行比较和提前停止铺平道路。
