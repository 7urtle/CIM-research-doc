9.0 全文总结：一条“算法-电路协同近似”的完整逻辑链

把整篇论文串成一句话：既然数字 CIM 的乘法太贵，那就换一个不需要乘法的算法（L1 距离），再为这个算法量身打造一套从分解式、位串行数据流到动态比较器的硬件。逻辑链：

  1. 问题：数字 CIM 乘法成本二次膨胀 + 电路近似伤精度 + 位级稀疏浪费（§2）；
  2. 算法地基：L1 距离替代点积（AdderNet），乘法消失、逼近能力相当（§3）；
  3. 架构优化：预计算分解 |x−w| = x+w−2·min(x,w)，减法/绝对值 → 最小选择，Σw 预存、Σx 共享（§4）；
  4. 电路实现：位串行比较 + MinMUX + 提前停止吃稀疏（§6）；动态逻辑改进比较器把电荷共享误差阈值从 2 提到 6（§7）；
  5. 软件配合：权重截断（+86× 稀疏度）、共享尺度量化、激活正则化（≤5 个「1」，0.9% 激活需处理）（§8）；
  6. 闭环验证：102 TOPS/W、4.4 TOPS/mm²、CIFAR-10 91.71% / ImageNet 74.8%，精度损失 <0.1%（§8）。
🎓 对本论文的评价（供思考）
  • 强：① 创新角度新——不是“把乘法做快”而是“让乘法不发生”；② 从算法到电路每一层都有对应收益，逻辑自洽；③ 首次 L1 距离 CIM + 首次 8-bit 超 100 TOPS/W 过 ImageNet；④ 部署流程免重训练，实用。
  • 弱/局限：① 只在卷积网络（ResNet 风格）上验证，未覆盖 Transformer/注意力；② 能效峰值依赖较高稀疏度（10% 输入 + 50% 权重），实际负载可能打折；③ 逐层映射（无跨层流水）限制了整体吞吐；④ 面积效率 4.4 TOPS/mm² 相比 5nm 级全数字 CIM（如 4790 TOPS/mm²/b）仍有差距——工艺代差与算法取舍使然。

9.1未来研究方向

  1. 扩展到 Transformer / 大语言模型：L1 距离能否用于注意力（Q·K 点积 → L1 相似度）？残差结构与更大动态范围的量化误差如何控制？这是 AdderNet 系列（Adder Attention [29]）已开始探索、但硬件 CIM 尚未充分覆盖的方向；
  2. 动态位宽 / 混合粒度：2–8 b 位宽可配已验证，可进一步做“层间/块间自适应位宽”甚至“逐通道位宽”，把线性成本优势用到极致；
  3. multiply-less 与 MAC 混合架构：并非所有算子都适合 L1（如归一化、Softmax），设计“L1 核 + 传统 MAC 核”混合的异构 CIM，按层动态切换；
  4. 支持在线训练 / 微调：L1 距离的梯度是符号函数（不可导处需平滑近似），硬件上做“前向 L1 + 反向近似梯度”的片上微调（[23] 的一步浮点微调思路可结合）；
  5. 双层稀疏调度：输入稀疏 × 权重稀疏联合利用——本工作已吃权重位稀疏，若再结合激活稀疏（输入稀疏）与提前终止，能效可进一步翻倍；
  6. 更先进工艺与三维集成：28nm 原型 → 5nm/4nm（参考 [17][18] 的工艺演进），配合 3D 堆叠提升容量与带宽，逼近全数字 CIM 的密度；
  7. 误差建模与自动正则化：把动态比较器电荷共享误差建成统计模型，训练时自动注入等效噪声 → 省掉手工正则化，精度/能耗权衡更优。

9.2术语表

术语解释
CIM（Compute-in-Memory）存内计算：把计算电路放进存储阵列，减少数据搬移。
MVM（Matrix-Vector Multiply）矩阵-向量乘，神经网络的核心运算原语。
Multiply-Less NN免乘法神经网络：用 L1 距离等加法运算替代乘加。
L1 距离（曼哈顿距离）Σ|x−w|，绝对差之和；本论文用它替代点积。
AdderNetCVPR 2020 提出的加法网络，本论文算法基础。
预计算（Precalculation）把静态可算的项（如 Σw）提前算好存起来，实时只算最便宜的项。
WSUM权重和 Σw，编译期预计算、存在 SRAM 额外列（15 单元/列）。
ActACCU / MinACCU激活累加器（Σx，广播共享）/ 最小值累加器（Σmin，时钟门控）。
ABS-ASM绝对值装配单元：汇合 Σx、Σw、2Σmin 输出部分和。
MinSEL / MinMUX最小值选择单元 / 最小值多路选择器（传输门实现）。
位串行（Bit-Serial）按位（MSB 优先）逐周期处理的数据流，位宽可配。
动态逻辑（Dynamic Logic）预充-求值型电路，面积小、速度快，但有电荷共享问题。
电荷共享（Charge Sharing）寄生电容与输出节点共享电荷导致电压跌落的效应。
提前停止（Early Stop）比较分出大小后停止预充/读取权重位，省读功耗。
8T SRAM8 管 SRAM 单元，本论文用于权重存储与读端口优化。
激活正则化限制激活二进制中「1」的个数（≤5），抑制电荷共享误差。
PTQ（Post-Training Quantization）训练后量化：不需重训练，直接量化部署。
TOPS/W每瓦每秒万亿次运算，能效单位（本论文 1 次比较+累加计 2 OPs）。
